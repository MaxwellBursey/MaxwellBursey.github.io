Password generation program

Overview

A command-line password generator that takes user constraints - length, required character classes - and produces passwords that satisfy them, using Python's secrets module for cryptographically secure randomness rather than the predictable random module.

Testing and delivery

The program was validated through systematic test cases covering constraint combinations and edge cases, with issues debugged and resolved along the way. I closed the project by building and delivering a presentation to the class walking through the design and the security reasoning behind the implementation choices.
